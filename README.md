# Hi, I'm Junfeng Yu (Jacob953) 👋

I lead engineering at **Touchine**, where I'm building [OJO](https://ojo.art/)—an AI-native design workspace that helps teams turn open-ended product ideas into researched, planned, editable, and production-ready web experiences.

My work sits at the boundary between model capability and production engineering: agent runtimes, workflow contracts, AI gateways, secure execution, distributed systems, databases, reliability, and developer experience.

- **Agent systems:** planning-first and contract-driven workflows, tool orchestration, memory, evaluation, and human-in-the-loop interaction.
- **AI infrastructure:** workload-aware model routing, prefix and dynamic caching, observability, cost control, and multi-tenant gVisor sandboxes.
